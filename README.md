# 📖 Overview

Navigating large indoor environments such as colleges, hospitals, airports, shopping malls, and corporate buildings can be challenging, especially for first-time visitors.

This project introduces an **AI-Powered 3D Holographic Navigation & Assistance System** that computes the shortest path using graph algorithms and presents navigation instructions through an interactive **3D holographic display**.

Unlike conventional navigation systems that rely on static maps, this solution provides an intuitive, immersive, and intelligent navigation experience by combining software algorithms with holographic hardware.

# 🧠 Algorithm Used

## Dijkstra's Shortest Path Algorithm

The indoor environment is modeled as a weighted graph.

- Nodes represent locations.
- Edges represent pathways.
- Edge weights represent distances.

The system computes the shortest path from the user's current location to the selected destination in real time.

### Why Dijkstra?

- Efficient
- Accurate
- Reliable
- Suitable for weighted indoor maps
- Guarantees the shortest route

# 🎯 Workflow

1. User launches the application.
2. Destination is selected using GUI or voice command.
3. Speech Recognition converts voice into text.
4. Destination is identified.
5. Indoor graph is loaded.
6. Dijkstra's Algorithm computes the optimal route.
7. Navigation path is visualized.
8. Corresponding hologram video is launched automatically.
9. Route is displayed on the 3D holographic fan.
10. Voice guidance assists the user throughout navigation.
